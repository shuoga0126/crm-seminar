このプロジェクト専用のSkillsを作成します。
.claude/commands/ フォルダにファイルを置くと、そのファイル名が /コマンド名 として使えるようになります。
ここに作ると、GitでCloneした全員が同じSkillsを使えます。

以下の2つのファイルを作成してください。

---

ファイル1: .claude/commands/review.md
内容：
まず git diff --name-only を実行して変更されたファイルを特定してください。

$ARGUMENTS でファイルが指定されている場合はそのファイルを、
指定がない場合は git diff --name-only で特定した変更ファイルを対象にしてください。
変更ファイルが0件の場合はプロジェクト内の全Pythonファイルを対象にしてください。

対象ファイルの内容を読み込んだ上で、以下の3点を日本語で番号付きリストで出力してください：

1. バグ・エラーの可能性がある箇所（該当行番号も記載）
2. 読みにくい・わかりにくい箇所
3. 改善できる箇所（提案がある場合のみ）

問題が見つかった場合は「修正しますか？」と確認してから修正してください。
修正後は「修正完了です。コミットに進みますか？」と報告してください。
問題がなければ「レビューOKです。コミットに進みます」と報告してください。

---

ファイル2: .claude/commands/pr.md
内容：
git diff main を実行して現在の変更内容を確認し、
GitHubのPull Request説明文を日本語で作成してください。
以下のフォーマットで出力してください：

## 変更内容
（何を変えたか）

## 変更理由
（なぜ変えたか）

## 確認してほしい点
（レビュアーに見てほしい箇所）

## 動作確認
- [ ] ローカルで動作確認済み

出力後、「この内容でPRを作成しますか？」と確認してから実行してください。
